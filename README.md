Langit Nusantara — an original Indonesian island-hopping flight game. Pilot the prop plane "Elang" (PK-LNG) between islands: thread the glowing target rings, then land on the island runway — smooth touchdowns score best. Seven-minute flights, fuel to watch, wind gusts, six legs, three lives. Chase view over turquoise sea, a volcano, rice terraces and coastal towns, with a full HUD (altitude, speed, heading, artificial horizon).

## Run it

```sh
python3 -m http.server 8080 --directory game
# open http://localhost:8080
```

Arrow keys / WASD to fly, Shift/Ctrl for throttle, G landing gear, F flaps, P pause, R restart, M mute.
